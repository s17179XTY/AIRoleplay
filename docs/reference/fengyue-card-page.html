角色与配置管理

在这里设定您的主人公和NPC信息，并将已选择的XP偏好分配给特定角色，实现更精细的剧情定制。
1.角色XP指的是角色自身喜欢的XP，该角色会因为什么兴奋，行为偏好等。
2.展现XP指的是该角色的特质，可满足或实现别人的某种XP，剧情主体等。
示例：XP为丝袜 / 偷窥 / 透视 / 哥布林 / 浴室
“角色XP”= 该角色喜欢丝袜 / 喜欢偷窥别人 / 拥有透视能力 / 喜欢哥布林 / 喜欢浴室
